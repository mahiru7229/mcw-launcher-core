# MCW Core v1.1.1

MCW Core is the GUI-independent runtime distributed with MCW Launcher.

## Package

- Distribution: `mcw-core 1.1.1`
- Runtime: `mcw_core.__version__ == "1.1.1"`
- Python: 3.12 or newer
- Wheel: pure Python `py3-none-any`

## Public API

The supported entry point is `import mcw_core`. Existing public contracts from v1.1.0 remain available. The v1.1.1 release adds the dependency-resolution, CurseForge identity, JarJar, legacy Forge, ATLauncher, and OptiFine improvements bundled by MCW Launcher.

See `docs/MCW_CORE_LIBRARY.md`, `docs/en/CORE_GUIDE.md`, and `docs/vi/CORE_GUIDE.md` in the source archive.
