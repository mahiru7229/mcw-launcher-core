# MCW Core v1.0.2

## English

MCW Core 1.0.2 aligns package metadata with MCW Launcher v1.0.2. The launcher restart correction is GUI-only and does not modify the public core API.

### Changed

- Package and runtime version metadata now report `1.0.2`.
- Distribution tests expect `1.0.2`.

### Unchanged

- Public API signatures and exports.
- Instance and package formats.
- Provider behavior.
- CurseForge configuration policy.
- Language and theme contracts.

## Tiếng Việt

MCW Core 1.0.2 đồng bộ metadata package với MCW Launcher v1.0.2. Bản sửa restart chỉ nằm ở GUI và không thay đổi public API của core.

### Thay đổi

- Metadata runtime và package chuyển thành `1.0.2`.
- Test distribution được cập nhật theo version mới.

### Không thay đổi

- Public API và chữ ký hàm.
- Định dạng instance/package.
- Hành vi provider.
- Chính sách cấu hình CurseForge.
- Contract language/theme.
