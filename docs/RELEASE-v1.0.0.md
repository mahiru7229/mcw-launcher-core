# MCW Core v1.0.0

First stable release of the public MCW Core library.

## Stable scope

- Headless core API separated from the launcher GUI.
- Stable import path under `mcw_core`.
- Public service access through `mcw_core.api`.
- Core support for launch, instance lifecycle, Java, mod loaders, provider integrations,
  portable packages, repair, diagnostics, backups, and content management.
- Documentation set prepared for the standalone core repository.

## Packaging

- Python wheel: `mcw_core-1.0.0-py3-none-any.whl`
- Source snapshot: `mcw-core-v1.0.0-repo.zip`

## Notes for 1.0.0

This release marks the first stable API contract for the MCW Core package.
Any future API removals should follow a documented deprecation cycle.
